# Segunda Proyección — sitio web

Landing page estática lista para GitHub Pages.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `segunda-proyeccion`.
2. Sube el contenido de esta carpeta a la raíz del repositorio.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda. GitHub mostrará la URL pública cuando termine el despliegue.

## Archivos

- `index.html` — contenido de la página
- `styles.css` — diseño responsive
- `script.js` — año automático en el pie
- `assets/logo-segunda-proyeccion.webp` — imagen optimizada
